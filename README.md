# 文字抽取成图 (Cutout Poster) v0.4.0 —— SillyTavern 扩展

## 安装
把整个 `cutout_poster` 文件夹放进 `SillyTavern/public/scripts/extensions/third-party/`，刷新酒馆页面。

## 本版更新
- 文字槽位不再显示 `{}`。
- 挖洞置换支持每块碎片独立尺寸：选中下方碎片后，在“样式 → 形状 → 当前碎片单独大小”调整。
- 顶部标题栏可拖动整个面板，支持触屏和鼠标。
- 导出文件使用独立文件名和 Blob URL，避免连续下载时复用链接；预设仍保留 JSON 扩展名。
- 新增七种模板：河流文字排版、像素碎片拼贴、圆形记忆档案、编辑部时间轴、档案研究展板、人物关系网络、天空图像嵌字（共七种）。

## 使用
在聊天中选中文字，点击选区附近的“抽取成图”；也可从扩展菜单打开。上传图片或使用角色头像、聊天背景作为底图。模板、文字和样式均可单独调整。

## 新模板说明
- 河流文字排版：文字重复形成蜿蜒的河道视觉。
- 像素碎片拼贴：完整照片与不同尺寸的像素块并置。
- 圆形记忆档案：圆形照片碎片聚集，配合下方整幅照片。
- 编辑部时间轴：左侧照片、右侧阶梯式事件列表。
- 档案研究展板：中央主图与四周编号注释。
- 人物关系网络：照片节点、连线与文字标签。
- 天空图像嵌字：将局部图像切片嵌入句子。

## 注意
模板脚本导入功能会执行用户导入的 JavaScript，只导入可信脚本。下载功能受浏览器自身权限策略影响；如果浏览器拦截多文件下载，请允许该站点下载多个文件。
