# 文字抽取成图 (Cutout Poster) v0.6 —— SillyTavern 扩展

## 安装
Git URL：扩展面板 → Install extension → 粘贴 https://github.com/你的用户名/cutout-poster
或把整个文件夹放进 SillyTavern/public/scripts/extensions/third-party/ 后刷新页面。

## 使用
- 选中聊天里的文字 → 选区下方出现「抽取成图」→ 点开面板（点完后选区会自动取消）。
- 点一下聊天里的图片 → 图片下方出现「用这张图制作」→ 直接用这张图开始。
- 按住标题栏可拖动整个面板（标题栏不会被拖出屏幕）；双击标题栏回到正中。
- 顶部图标依次：撤销、清除、保存图片、显示/隐藏设置、关闭。
- 设置按功能分六页：素材（模板/文字/图片）、版面、元素（形状/大小/字块）、文字、外观（颜色/质感）、更多。没有内容的页会自动隐藏；每个分区卡片的标题可点击折叠。
- 预览和设置之间有一条拖动条：上下（横屏时左右）拖动调整两边大小，双击恢复默认。
- 防误触：滑杆只有按住圆点左右拖才会改值（点轨道不动、上下滑动是滚动页面），两端有 −/+ 微调按钮；
  改了参数不小心碰错，可以点顶部「撤销」退回上一次的参数改动。
- 保存图片：弹出预览，可「下载」「分享/存相册」「复制」；下载没反应时，长按预览图保存。
- 图片：上传 / 角色头像 / 聊天背景 / URL；「裁剪 / 调整大小」可拖动、缩放、换比例。

## 模板（全部手动操作）
1. 挖洞置换：点图挖洞；洞可拖动、单独调大小；「洞的角度」和「碎片的角度」分开调；
   形状含拼图/水滴/四角星等，还能手绘形状或用图片做形状；
   碎片可放在图旁（对应位置/聚拢/网格/排成一个字）、图外边框里、或直接替换文字里的字。
2. 涂黑诗：点词留字，黑块只出现在留字的范围内。
3. 验证码九宫格。
4. 文字塑形：沿画面暗/亮区域、填满形状、波浪线、圆环/螺旋、竖排。
5. 切边时间表：每行文字一个色块，图上拖动调切入深度。
6. 检测框关系图：图上拖框，下方生成关系图。
7. 图版标注：标题 + 说明 + 罗马数字图例。
8. 缺字填空：点字挖空变成字块；空洞/字块形状可换（含自定义形状），每个空洞、字块大小都可以单独调；
   字块可拖到任意位置；文字区/字块区背景都可换成图片；文字排版可调（横排/竖排、对齐、行距、字距、边距）。

## 字体 / 预设 / 模板脚本
「更多」页：导入字体文件（ttf/otf/woff/woff2）、手动输入字体名、导出/导入预设(.json)、导入模板脚本(.js，只导入你信任的文件)。
默认字体跟随酒馆主题。

模板脚本格式：
    CutoutPoster.register({
      id: 'mine', name: '我的模板', hint: '提示',
      defaults: { color: '#ff0000' },
      controls: [{ group: '颜色', key: 'color', label: '颜色', type: 'color' }],
      render(cv, ctx, P) { /* 设 cv.width/height 后画图；文字在 CutoutPoster.util.S.text */ }
    });
可选钩子：onDown(x,y,P,ui) / onMove / onUp / snap / restore / clear / exportOk。
